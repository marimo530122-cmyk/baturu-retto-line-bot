# 声の感情の実験(手元・GitHub だけ。本番には入れない)

「声のトーンや抑揚から感情を読むと、詐欺の見分けがよくなるか」を、数字で確かめるための道具。
本番(Render)と見守り画面のマイクの処理には、一切さわらない。

## 何を確かめるか

1. 詐欺の電話の声で、「怒り」「恐れ」「驚き」はどれくらい出るか(詐欺師は落ち着いて丁寧に話すことが多い)。
2. 普通の電話(家族・お店・病院など)と比べて、はっきり差があるか。
3. 差があっても、今の文字の判定(誤検知 0/93)より誤検知が増えないか。

1だけでは結論を出さない。2と3の比べ(普通の電話の録音)が無いと、本番に入れる理由にはならない。

## いちばん楽なやり方(PCなし・スマホから)

警察が公開している録音で試すなら、GitHub だけで動く。

1. GitHub のアプリで、このリポジトリの「Actions」→「voice-emotion-experiment」→「Run workflow」。
2. ページのURL(初めは静岡県警「サギ電話を聞いてみよう!」)はそのままで実行。
3. 10〜20分で終わる。実行結果の「Summary」に、ファイルごとの感情の割合が表で出る。

自分や家族の電話の録音は、ここに使わない(公開リポジトリなので)。下のPCのやり方で、手元だけで調べる。

## PCで動かす(Windows / Mac)

### 1. 準備(最初の1回だけ)

- Python 3.11 を入れる: https://www.python.org/downloads/ (Windows は「Add python.exe to PATH」にチェック)
- ffmpeg を入れる:
  - Windows: PowerShell で `winget install Gyan.FFmpeg`
  - Mac: ターミナルで `brew install ffmpeg`(Homebrew が無ければ https://brew.sh )

このフォルダ(`sengoku-shield/experiments/voice-emotion`)で:

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate   /   Mac: source .venv/bin/activate
pip install torch torchaudio --index-url https://download.pytorch.org/whl/cpu
pip install -r requirements.txt
```

GPU は要らない(CPUで動く)。メモリは 4GB 以上あると安心。初回はモデル(数百MB〜1GBくらい)をダウンロードする。

### 2. 調べる

```bash
python analyze.py sample_fraud.wav
```

詐欺の録音と普通の電話の録音を比べるときは、フォルダを分けて入れる:

```
samples/
  fraud/   ← 詐欺の電話(警察の公開録音など)
  normal/  ← 普通の電話(本人と相手の了解を取ったもの)
```

```bash
python analyze.py samples/ --label-from-folder --sensevoice
```

- 画面に、ファイルごとの「多かった感情 上位3つ」が出る。
- `emotion_summary.md` にまとめの表、`emotion_results.csv` に数秒ごとの細かい結果が出る(Excel で開ける)。
- `--sensevoice` を付けると、文字起こしと話す速さ(1秒あたりの文字数)も出る(遅くなる)。

### 出てくる数字

- 感情は9種類(怒り・恐れ・驚き・悲しみ・嫌悪・喜び・平静・その他・不明)の割合(合計100%)。
- **「焦り」という種類は、このモデルには無い。** 代わりに、焦りの手がかりとして次も出す:
  - `chars_per_sec`(話す速さ。`--sensevoice` のとき)
  - `loudness_db`(声の大きさ)
  - `pitch_spread`(声の高さの揺れ。抑揚が大きいほど大きい)
- 割合はモデルの推定で、確率として較正されたものではない。数本で結論を出さない。

## 電話越しのこもった音声の前処理

`--filter` で選べる(既定は `light`)。

| 指定 | 中身 | 使いどころ |
|---|---|---|
| `none` | そのまま | まず比べる基準に |
| `light` | 150Hz以下と3800Hz以上を落とし、音量をそろえる | 電話の音(300〜3400Hzしか通らない)に合わせる。基本はこれ |
| `denoise` | `light` + 雑音を弱める | 「サー」という雑音が大きい録音だけ |

気をつけること:

- **雑音を消しすぎると、声の感情の手がかり(息づかい・声の震え)も消える。** 必ず `none` と比べる。
- 録音ごとに音量がばらばらだと、「声が大きい=怒り」と出やすい。`light` で音量をそろえる。
- スピーカーから出た電話の声を、別のスマホで録った音は、さらにこもる。本番に近い条件で試すなら、
  見守り画面と同じ置き方(電話をスピーカーにして、そばのスマホで録音)で録った音も用意する。
- 警察の公開録音は、ピー音や説明のナレーションが混ざっていることがある。結果のCSVで、その区間を見分けて外す。

## 決まり

- 例文と同じく、確かめた本物の録音だけを使う。Gemini などが作った音声は使わない。
- 普通の電話の録音は、本人と相手の了解を取ったものだけ。結果のCSV(文字起こしが入る)は Git や SNS に上げない。
- 音声は保存しない(analyze.py は一時ファイルをすぐ消す)。声のクローンには使わない。
- 結果がよくても、そのまま本番には入れない。普通の電話での誤検知を確かめてから、利用者と相談して決める。
- 使うモデルの使用条件(emotion2vec・SenseVoice のライセンス)は、本番に入れる前に確かめる。

## これまでの結果

### 2026-10-25 静岡県警「サギ電話を聞いてみよう!」11本(前処理なし、emotion2vec+ base)

| 本 | 多かった感情(区間の平均 上位3つ) |
|---|---|
| 01 | 平静 87% / 怒り 10% / 嫌悪 2% |
| 02 | 平静 58% / 悲しみ 27% / 喜び 10% |
| 03 | **喜び 69%** / 平静 11% / 嫌悪 6% |
| 04 | 平静 35% / 喜び 21% / 悲しみ 16% |
| 05 | 平静 36% / 恐れ 33% / 喜び 21% |
| 06 | 平静 49% / **喜び 43%** / 悲しみ 4% |
| 07 | 平静 36% / 驚き 20% / 悲しみ 15% |
| 08 | 平静 44% / 悲しみ 25% / 嫌悪 10% |
| 09 | 平静 55% / 悲しみ 19% / 喜び 9% |
| 10 | 平静 41% / 悲しみ 34% / 恐れ 9% |
| 11 | 平静 74% / 喜び 19% / 驚き 4% |

- 11本中10本で「平静」がいちばん多い。怒り・恐れ・驚きがいちばん多い本は無い。
- 「喜び」が多い本がある(03・06)。愛想のよい丁寧な話し方が「喜び」と読まれていると考えられる。
- つまり、**声の感情だけでは詐欺らしさはほとんど出ない**(詐欺師は落ち着いて愛想よく話す、という予想どおり)。
- 録音には被害者役の声・説明の声も混ざっている。話している人ごとに分けて測っていないので、数字はおおまか。
- 普通の電話の録音とまだ比べていない。比べないと「差があるか」は言えない。
