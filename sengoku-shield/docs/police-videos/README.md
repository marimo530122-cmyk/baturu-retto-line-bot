# 警察の防犯動画から集めた手口

全国の警察署・県警が YouTube や TikTok で出している防犯動画を、利用者が Gemini で要約して Claude Code に送り、
ここに1本1ファイルでためていく。戦国シールドの例文(ベンチマーク)と検知ルールを、作りものではなく
**実際の犯人の言い回し**で育てるための材料。

## ファイルの形

`YYYY-MM-DD-<警察署や県警の名前>.md`(日付は動画の公開日。わからなければ送ってもらった日)

```markdown
# <動画のタイトル>

- 出どころ: <チャンネル名(警察署・県警名)>
- URL: <動画のURL>
- 公開日: <YYYY-MM-DD または 不明>
- 受け取った日: <YYYY-MM-DD>
- 要約した人: Gemini(利用者が送付)

## 手口
<手口の種類(ニセ警察官・還付金・オレオレ・投資・サポート詐欺など)と流れ>

## 犯人の言い回し(動画の中で実際に出てきたものだけ)
- 「……」(0:42)

## 本物との見分け方・警察からの呼びかけ
- ……

## 戦国シールドへの反映
<Claude Code が書く: 例文に入れたか(dev / holdout)、ルールを直したか、対象外の理由>
```

## 決まり

- **言い回しは動画で実際に言っていたものだけ**。Gemini の言い換えや想像は入れない(できれば何分何秒かも)。
  動画を見ていない要約(タイトルや説明文だけからの推測)は、手口の参考にとどめ、例文には使わない。
- **動画の書き起こしを丸ごと貼らない**。このリポジトリは公開されているので、短い引用と要約、URL だけにする(著作権のため)。
- **被害者・警察官・銀行員の個人名は書かない**(動画に出ていても)。
- 新しく集めた言い回しは、**半分ずつ dev と holdout に分けて**例文に入れる。先に holdout で今のシールドの実力を測り、
  ルールは dev だけを見て直す(holdout に合わせて直すと、数字が実力以上に良く見えるため)。
- 電話以外の手口(フィッシングのSMS・偽サイト・パソコンの警告画面)は、記録はするが戦国シールドの対象外と書く。
