- 公開日: 2018年〜2025年(ファイル名の日付)

- 要約した人: Claude Code(GitHub Actions で音声を文字起こしして、犯人の言葉を選んだ)

## 手口
ニセ警察(他県警に「転送」→電話で事情聴取→事件専用のLINEへ)、還付金(区役所の「累積医療費」→銀行・ATM)、
オレオレ(携帯をなくした→会社のお金・株の使い込み)、ニセ百貨店・ニセ銀行協会(カード)、サポート詐欺(電話)。

## 鮮刻シールドへの反映(警視庁と千葉県警の分をまとめて)
- 文字起こしは `.github/workflows/transcribe-police-audio.yml`(faster-whisper)。音声も全文もリポジトリには置かず、
  犯人の言葉だけを短く引用した(`scam-samples.json` の s067〜s129)。明らかな変換ミスは補正し、名前・地名の一部は外した。
- **判定にかける前に** dev / holdout を決めた。同じ相手への続きの電話(同じページの連番)は同じ側にまとめ、
  中身は見ずに、そのときの件数が少ない方へ入れた(dev 32 / holdout 31)。
- 直す前(今のルールのまま): 新しい実録音で dev 11/32、**holdout 10/31(32%)**。
- dev の見逃しだけを見てルールを足した: medical_refund・past_deadline・bank_will_call・office_to_bank(還付金)、
  arrest_list(名簿・逮捕)、lost_items・dont_call_phone・answer_for_me・alone_check(携帯をなくした下準備)、
  borrow_money・withdraw_wait・embezzle・repay_soon(お金の頼み)。proxy_pickup に「会社の子」、secrecy に「誰にも言ってない」、
  authority に「厚生労働省」「福祉課・保険課・年金課」を足した。
- 「生活安全課」「捜査2課」だけでは拾わないことにした(本物の警察の電話 b018・b085 と見分けられないため)。
- 直した後: 新しい実録音で dev 27/32、**holdout 16/31(52%)**。全体では dev 69/76、holdout 23/53、誤検知 0/93
  (家族・役所・病院のふつうの電話 b089〜b093 を足して確かめた)。holdout の見逃しには合わせていない。
- dev でまだ拾えないもの: 待ち合わせの道案内だけの電話、「封筒は別々?」のような受け取りの確認、「捜査2課の者ですが」の一言だけ。
