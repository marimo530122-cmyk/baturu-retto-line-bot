パソコンでやること

戦国シールドを、試作品から「実際に動くもの」にするための、パソコンでの作業のまとめです。上から順にやれば動くように並べてあります。

Jevは「入れる」ものではありません

Jev(TypeSafe)はインターネット越しに使うサービスです。TypeSafeで発行したキーを戦国シールドのサーバーの設定に書き込めば、それだけで使えます。スマホの見守り画面はサーバーの判定を使うので、サーバーにJevのキーを入れれば、スマホでも自動的にJevが使われます。スマホに何かを入れる必要はありません。

全体の順番

  1. キーを集める(ブラウザだけでできる。30分〜1時間)
  2. パソコンで動かしてみる(パソコンを起動している間だけ動く「試運転」)
  3. スマホで見守り画面を開いて試す
  4. 24時間動かす(パソコンを切っても動くよう、インターネット上のサーバーに移す。これは後日でOK)

2と3は、パソコンのClaude Codeに任せられます(下の「Claude Codeに渡す指示文」)。

1. キーを集める(ブラウザで)

それぞれのサイトでアカウントを作り、キーを取り出します。キーは他人に見せないでください(チャットにも貼らない)。

何のためどこで取り出すもの → 設定の名前
AIの返事(Claude)console.anthropic.comAPIキー → ANTHROPIC_API_KEY
詐欺の判定・相手の様子(Jev)TypeSafe のサイトAPIキー → TYPESAFE_API_KEY
家族へのLINELINE Developers(戦国シールド専用のMessaging APIチャネルを新しく作る)チャネルシークレット → LINE_CHANNEL_SECRET
チャネルアクセストークン(長期) → LINE_CHANNEL_ACCESS_TOKEN
友だち追加URL → SHIELD_LINE_ADD_URL
電話(AIの応答・家族への自動電話)Twilio(日本の電話番号を1つ取る。住所確認の書類が必要)Account SID → TWILIO_ACCOUNT_SID
Auth Token → TWILIO_AUTH_TOKEN
取った番号(+81〜) → SHIELD_CALLER_ID

LINEは、バツルーレットの配信で使っているチャネルとは別に作ってください。Twilioの日本の番号は、審査に数日かかることがあります。全部そろっていなくても、あるものから試せます(ないものは「未設定」として動きます)。

2. パソコンで動かしてみる

最初に入れるもの

  • Node.js 22 以降(nodejs.org の「LTS」版)
  • Git
  • cloudflared(パソコンで動かしたサーバーに、外(Twilio・LINE・スマホ)から届くURLを付けるための道具。Cloudflareの公式サイトから無料で入れられます)
  • Claude Code(作業を任せるなら。入れ方は code.claude.com の公式案内に従ってください)

ダウンロードとテスト

git clone -b claude/main-2thn7e https://github.com/marimo530122-cmyk/baturu-retto-line-bot.git
cd baturu-retto-line-bot/sengoku-shield
npm install
npm test

戦国シールドはまだ claude/main-2thn7e ブランチにあります(main には入っていません)。リポジトリが非公開なら、GitHubへのログインを求められます。npm test で全部のテストが通れば準備OKです。

キーを書き込む

cp .env.example .env

できた .env をメモ帳などで開き、1で集めたキーを「=」の右に書き込みます。.env はGitHubには上がりません。

起動して、外から届くURLを付ける

# 1つ目の画面(ターミナル)で: 外から届くURLを取る
cloudflared tunnel --url http://localhost:3000
#   → https://〜.trycloudflare.com のようなURLが出るので、.env の SHIELD_PUBLIC_URL に書く

# 2つ目の画面で: サーバーを起動
npm run start:env

# 3つ目の画面で: 全部につながるか確かめる
npm run check

npm run check は、Claude・Jev・LINE・Twilio・公開URLにつながるかを1行ずつ ○ × で出します。見守り画面の合言葉(SHIELD_APP_TOKEN)が空なら、使える候補も出します。LINEとTwilioに設定するWebhookのURLも教えてくれます。

試運転のURLは、cloudflaredを起動し直すたびに変わります。変わったら .env と LINE・Twilio の設定も書き換えてください(24時間動かす段階で固定のURLにします)。

3. スマホで試す

  1. スマホのブラウザ(Chrome か Safari)で https://〜.trycloudflare.com/app を開き、画面下に合言葉を入れる。
  2. 「見守り家族」で「家族を登録する」を押し、出た6桁の番号を、自分のスマホから戦国シールドのLINEに送る(電話番号も送る)。
  3. 「文字で試す」に「市役所です。還付金があるので今日中にATMに行ってください」と入れ、警告が出ることを確かめる。
  4. 「AIに代わってもらう」を押してから、「みずほ銀行新宿支店、口座番号は1234567です」と入れる → AIが聞き返し、自分のLINEに口座が届き、自動電話が鳴ることを確かめる。

4. 24時間動かす(後日)

パソコンを切ると戦国シールドも止まるので、本番ではインターネット上のサーバー(クラウド)に移します。Node.js が動いて、ファイルを保存しておける場所(家族の名簿を置くため)があるサービスなら使えます。どこにするかは、試運転がうまくいってから、Claude Codeと一緒に決めましょう。

Claude Codeに渡す指示文

パソコンでClaude Codeを起動し(baturu-retto-line-bot フォルダで)、下の文をそのまま貼り付けてください。

このリポジトリの sengoku-shield(戦国シールド)を、このパソコンで動かすのを手伝ってください。ブランチは claude/main-2thn7e です。急いで、でも確実に進めてください。

1. Node.js(22以降)・git・cloudflared が入っているか確認し、足りないものは入れ方を教えてください。
2. sengoku-shield で npm install と npm test を実行し、全部通ることを確認してください。
3. .env.example を .env にコピーしてください。キーは私が自分で .env に書き込みます(チャットには貼りません)。どの行に何を書くかだけ教えてください。
4. cloudflared tunnel --url http://localhost:3000 で公開URLを取り、.env の SHIELD_PUBLIC_URL に入れて、npm run start:env でサーバーを起動してください。
5. npm run check を実行し、× があれば原因を調べて直してください。
   Jev(TypeSafe)の応答の形が想定と違うと出たら、TypeSafe の公式ドキュメントと実際の応答に合わせて lib/jev.js と check.js の読み取り方を直し、テストも直して npm test を通してください。
6. LINE Developers と Twilio に設定する Webhook の URL を教えてください。
7. 最後に、スマホで見守り画面(/app)を開いて、警告・AIへの交代・家族へのLINEと自動電話を試す手順を教えてください。

CLAUDE.md と sengoku-shield/README.md の方針は必ず守ってください(AIは振り込む・渡す等の約束をしない、声のクローンは入れない、AIが自分で110番しない、警察への自動送信はしない、など)。

コピーできないときは、上の文を長押しして選んでください。

キーの扱い: キーはお金がかかるサービスの合言葉です。.env に書くだけにして、チャット・LINE・スクリーンショットで人に見せないでください。うっかり見せてしまったら、そのサイトでキーを作り直してください。
