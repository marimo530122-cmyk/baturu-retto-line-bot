# 詐欺の手口情報の受け渡し(scam-intel)

新しい手口の情報は、このファイルで受け渡す。**検知ルールの作業を始めるときは、まず「未処理」を確認する。**

## 決まり

- 1件 = 1つの見出し。新しい件は「未処理」の一番上に足す。処理が終わったら「処理済み」へ移し、結果を書く。
- 書くこと:件名・出典(どこの公式情報か・受付日)・手口の要点・評価してほしい観点。
- 出典は公式のもの(警察庁・各県警・自治体・日本郵便など)を書く。Gemini などがまとめた文は「未確認」と書く。
- 手口の説明は**例文ではない**。公式の文字起こし・本文で確かめた言い回しだけを例文(`scam-samples.json`)にし、
  そのときは dev と holdout に半分ずつ分ける(決まりは `docs/police-videos/README.md`)。
- 評価では holdout の例文・録音を読まない。数字(何件中何件)だけを見て、それに合わせてルールを直さない。
- ルール案は、`evolve.js` と同じ機械チェック(例文・当たってはいけない例・普通の電話93件・遅さ・ベンチマークの前後)まで。
  反映(`node evolve.js approve`)・マージ・デプロイは、利用者の承認のあと。
- 普通の電話が新しく「疑い:中」以上になる案は出さない。

### 機械チェックのやり方

```bash
cd sengoku-shield
node docs/scam-intel/check-proposals.js . docs/scam-intel/<件>.proposals.json docs/scam-intel/<件>.probes.json
```

`<件>.proposals.json` はルール案(`evolve.js` の提案と同じ形)、`<件>.probes.json` は試しの文(合成。例文には使わない)。

### 承認されたら

1. `<件>.proposals.json` の中身を `data/proposals/pending.json` に入れ、`node evolve.js approve <id>` で1つずつ反映する
   (反映のときにもう一度ベンチマークが回り、監査ログに記録される)。
2. `npm test` を通し、`patterns.custom.json`・`audit/`・`evidence/` をコミットする。

#### 足りないもの

1. **「逮捕状」以外の言い方**:「逮捕令状」「あなた名義の令状が出ています」「このままだと身柄を拘束する」は、どのルールにも当たらない。
2. **「捜査に必要」名目のお金**:「捜査に必要なので、お金を確認させてもらいます」「お金は捜査が終わったらお返しします」は、どのルールにも当たらない。
   警察を名乗る+逮捕状+この言い方の流れでも「中」止まり。
3. **警察の名乗りと LINE の誘いが別の文に分かれたとき**:「警察の者ですが」→「LINEでビデオ通話をしてください」は、
   `police_video_call` が1文の中で両方を見る作りのため当たらない(「低」)。正規表現では文をまたげないので、Jev の質問で補う案を下に書く。
4. 「実在の裁判官・検察官の名前」そのものは、名前が本物かどうかを電話の言葉から見分けられないので、ルールにはしない
   (`authority`・`unpaid_legal` が「裁判所」「裁判」「検察」で当たっている)。

#### Jev の質問の案(未実装。文をまたぐ流れを補う)

TypeSafe 公式スキル(typesafe-ai/skills の typesafe-ai スキル)の作法に合わせ、「詐欺か?」と1つで聞かずに、見て分かる1つずつの判断に分ける。
答えの組み合わせはコード(`lib/jev.js` の `combine()`)で決める。すべて Noul(はい/いいえ)。型名・書き方は公式ドキュメントで確かめてから実装する。

| 質問(相手=`transcript` の caller) | はい(true) | いいえ(false) |
|---|---|---|
| 相手は、聞き手に逮捕状(令状)が出ていると言っていますか | 聞き手本人に逮捕状・令状が出ている、出されると告げている | 逮捕状の話が出ない。または、ニュースや他人の事件、詐欺の手口の説明として話している |
| 相手は、警察手帳や書類を見せるために、LINE やビデオ通話に移るよう求めていますか | LINE の友だち追加・ビデオ通話・テレビ電話に誘っている | 電話のまま話を続けている。または、警察はビデオ通話をしないと注意しているだけ |
| 相手は、捜査を理由に、聞き手のお金・預金・口座の残高を求めていますか | 捜査・確認・鑑定のためとして、お金を渡す・移す・見せる・残高を言うよう求めている | お金の話が出ない。または、警察はお金を求めないと注意しているだけ |
| 相手は、事件の担当として裁判官または検察官の名前を出していますか | 特定の裁判官・検察官の名前を、聞き手の件の担当として出している | 名前を出していない。または、一般的な制度の説明をしている |

コードでの組み合わせ(案):1つ目が「はい」で、2つ目か3つ目も「はい」なら、`police_video_call` と同じ重さの手がかりとして扱う。
