# 本物の電話での試験 台本(家族に犯人役をしてもらう)

**いちばん確かめたいこと**:電話のスピーカーから出た相手の声を、そばに置いたスマホ(見守り画面)がちゃんと文字にできるか。
画面の判定(詐欺らしさ)の良し悪しより、まず「聞き取れるか」「AIの声が電話の向こうに届くか」を見る。

所要時間:準備10分 + 5つの場面 各3分くらい = 30分ほど。

---

## 用意するもの・人

| 役 | 人 | 使うもの |
|---|---|---|
| 犯人役 | 家族(息子・娘など) | 自分の携帯電話。この台本 |
| 本人役 | お母さん・お父さん(または本人役の家族) | 実家の電話(固定電話か携帯)、見守り画面を開いたスマホ |
| 記録係 | あなた | 下の「記録用紙」とペン(本人役のそばで画面を見る) |

## 準備(10分)

1. 本人役のスマホで、Chrome(iPhone は Safari)で `sengoku-shield.onrender.com/app` を開く。
   **開くまで1分ほどかかることがある**ので、試験の5分前に一度開いておく。
2. 「設定・ためし」で合言葉が入っているか確かめ、閉じる。
3. 静かな部屋で、テレビ・ラジオは消す(まずは良い条件で試す。うるさい条件は2回目に)。
4. 本人役の電話の横に、見守りのスマホを置く(電話のスピーカーから30cmくらい)。
5. スマホの音量を半分くらいにする(AIの声と「ポーン」が聞こえるように)。

## 大事な約束(必ず守る)

- **本当に110番しない。** 画面に「すぐ110番」と出ても、これは試験です。押さない。
- 犯人役は、**実在の人の名前・本物の口座番号を言わない**(台本の名前と番号だけを使う)。
- 試験の録音や画面の写真を、SNS に上げない。
- 本人役が本当にこわくなったら、すぐやめる(あらかじめ「今から試験の電話をするよ」と伝えておく)。
- 結果に合わせて、検知のルールを直すことはしない(数字が実力以上に良く見えるため)。直したいところは、記録だけしておく。

---

## 毎回の流れ

1. 犯人役が、本人役の電話にかける。
2. 本人役は電話に出たら、**スピーカーにする** → 見守り画面の **「聞き取りを始める」** を押す。
3. 犯人役が、台本のセリフを **1つずつ、普通の速さで** 言う(1つ言ったら、本人役の返事を待つ)。
4. 本人役は、ふだんどおり「はい」「ええ」などと返事をする。
5. 画面に①②が出たら、本人役は①の言葉を読み、**②のボタンを押す**(場面によって押さない。各場面に書いてある)。
6. AIが話し始めたら、犯人役はAIに向かってセリフの続きを言う。
7. 終わったら電話を切り、本人役は **「電話が終わったら押してください」** を押す。
8. 記録係は、記録用紙に書く。

## 場面A 市役所の還付金(基本)

**犯人役のセリフ**
1. 「もしもし、藤枝市役所の保険年金課の者です」
2. 「医療費の払い戻しがありまして、お知らせのはがきを送ったんですが、届いてますか」
3. 「期限が今日までなんですよ」
4. 「お近くのATMで手続きできますので、携帯電話を持ってATMに行ってもらえますか」

**本人役**:①②が出たら、①を読んで②を押す。AIに代わったら、犯人役は「では、どこのATMに行けますか」などと続ける。

**期待すること**:2〜3つ目で「少し気になる電話です」、4つ目で「大丈夫です。落ち着いてくださいね」と①②が出る。

## 場面B 警察かたり・口止め・口座

**犯人役のセリフ**
1. 「もしもし、静岡県警の捜査二課の田中と申します」
2. 「あなたの口座が、詐欺グループに悪用されていることが分かりました」
3. 「捜査上の守秘義務がありますので、ご家族や銀行の人には絶対に話さないでください」
4. 「口座を確認しますので、どちらの銀行に口座をお持ちか教えてください」
5. 「安全のため、お金を指定の口座に移してもらいます。振込先は、まるまる銀行の、口座番号 1234567 です」

**本人役**:①②が出たら、①を読んで②を押す。AIが「お名前と所属をもう一度」などと聞き返したら、犯人役は答えてよい。

**期待すること**:3つ目あたりで①②が出る。5つ目の口座番号が、画面の「警察に伝える手がかり」に出る。

## 場面C 息子かたり・会う約束(急ぎ)

**犯人役のセリフ**
1. 「もしもし、オレだけど。風邪ひいて声が変なんだ」
2. 「実は、会社のお金が入ったかばんを、電車に置き忘れちゃって」
3. 「今日中に300万円必要なんだ。誰にも言わないで」
4. 「オレは行けないから、会社の後輩が取りに行くよ」
5. 「明日の午後3時に、藤枝駅の改札で渡してほしい」

**本人役**:②は **押さない**(自分で応対したときの画面を見るため)。

**期待すること**:3つ目あたりで①②が出る。5つ目のあと、画面に「相手が、会う日時や場所…すぐに110番」と出る(**本当にはかけない**)。

## 場面D 普通の電話(病院の予約確認)— 間違えて警告が出ないか

**犯人役(ここでは病院の人)のセリフ**
1. 「もしもし、まるまるクリニックです。明日の午前10時のご予約の確認でお電話しました」
2. 「保険証とお薬手帳をお持ちください」
3. 「お変わりなければ、そのままお越しください」

**期待すること**:最後まで「聞き取り中」のまま。①②は出ない。

## 場面E 普通の電話(家族)— 間違えて警告が出ないか

**犯人役(ここではふだんの家族)のセリフ**
1. 「もしもし、お母さん? 今度の日曜に、孫を連れて遊びに行くね」
2. 「お昼は何か買っていくよ」
3. 「じゃあ、また電話するね」

**期待すること**:最後まで「聞き取り中」のまま。①②は出ない。

## 記録用紙(場面ごとに1行)

| 場面 | 文字になったセリフの数(○/全部) | ポーンが鳴ったのは何番目のセリフのあと | ①②が出た | AIの声は電話の向こうで聞き取れた(犯人役に聞く) | AIの返事は自然だった | 気づいたこと |
|---|---|---|---|---|---|---|
| A | /4 | | はい・いいえ | よく聞こえた・小さい・聞こえない | はい・いいえ | |
| B | /5 | | はい・いいえ | | | |
| C | /5 | | はい・いいえ | (AIなし) | (AIなし) | 110番の表示: 出た・出ない |
| D | /3 | | 出なかった・出た | (AIなし) | (AIなし) | |
| E | /3 | | 出なかった・出た | (AIなし) | (AIなし) | |

「文字になったセリフ」は、見守り画面の「設定・ためし」→「会話」に出ている文で数える(多少の聞き間違いはOK。意味が分かれば○)。

## 2回目(余裕があれば)

- テレビを小さくつけた部屋で、場面A と D だけもう一度。
- スマホを電話から1m離して、場面A をもう一度。

## 終わったら、Claude に送るもの

1. 記録用紙の写真(または、場面ごとに声で「Aは4つ中3つ文字になった、ポーンは3つ目」などと送る)。
2. 場面Bの「設定・ためし」→「会話」の画面のスクリーンショット(聞き取りの間違い方を見るため)。
3. 犯人役の人の感想(AIの声は機械っぽかったか、話の間はどうだったか)。
