# 藤枝警察署・地域防犯発信情報まとめ(特殊詐欺・トクリュウ対策)

藤枝警察署(藤枝防犯チャンネル等)が発信している内容を、利用者がまとめたもの。
戦国シールドの検知ルールと聞き出しの作戦は、この地元の実態に合わせている。
(出典はショート動画などの要約で、警察の公式資料そのものではない。警察署でのヒアリング(`hearing.html`)で確かめて更新する)

藤枝警察署に電話で確認したところ、この防犯動画(YouTube・TikTok)は、藤枝・焼津・島田・牧之原あたりの
4つの警察署で合同で作っているとのこと(署名は利用者の聞き取りで、正確な組み合わせは未確認)。
他の地域・全国の警察の動画のまとめは `police-videos/` に集める。

## 1. 現場で多発している手口

- **ニセ警察官・金融庁・市役所詐欺**:「あなたの口座が不正利用されている」「医療費の還付金がある」と騙り、
  キャッシュカードや現金の受け渡し(受け子)、または振込を指示する。
- **守秘義務の口止め(最重要)**:「捜査上の守秘義務があるため、家族や銀行員には絶対に話すな」と強く念押しし、
  高齢者を孤立・沈黙させる。
- **サポート詐欺・フィッシング詐欺**:パソコンの警告画面やSMSから偽サイトへ誘導し、口座番号・暗証番号・個人情報を入力させる。

## 2. 警察・金融機関・行政の連携状況

- **最後の砦(金融機関)**:藤枝署管内(静岡銀行藤枝駅支店など)では、窓口で口止めされた被害者から事情を紐解く水際阻止に
  注力しているが、高齢者が犯人の指示を信じ切っているため説得が難航している。警察から金融機関へ感謝状も贈られている。
- **トクリュウ(匿名・流動型犯罪グループ)**:指示役・掛け子・受け子が分断されており、現場に来る受け子の特定や
  振込先口座番号の即時把握が検挙の鍵。

## 戦国シールドでの反映

| 現場の壁 | 戦国シールドでの対応 | 場所 |
|---|---|---|
| 「守秘義務だから誰にも言うな」の口止め | 口止め(守秘義務+話すな)を検知する。口止めだけでは警告は出さない(本物の守秘義務の説明と区別するため) | `lib/detector.js` の `secrecy` |
| 窓口でうその理由を言わせる | 「銀行で聞かれたら〇〇と答えて」を検知し、それだけで「疑い:中」 | `lib/detector.js` の `bank_cover_story` |
| 口止めで本人が黙ってしまう | AIに代わった後は、AIが「分かりました、誰にも言いませんから安心してください」と話を合わせる。相手に言うだけで、家族への知らせはいつも通り送る | `lib/elicit.js` |
| ニセ警察官の身元 | 警察を名乗ったら「警察の方なら、メモをちゃんと残したいので、お名前と所属をもう一度」と聞き返す。所属(警察署・課)も手がかりとして残し、110番の台本に入れる | `lib/elicit.js`、`lib/intel.js` の `org` |
| 口座・受け渡し場所の即時把握 | 聞く順番を「(警察を名乗ったら名前と所属)→ 振込先(銀行・口座)→ 受け渡しの日時と場所 → 金額 → 折り返し番号」にした | `lib/elicit.js` の `ORDER_AUTHORITY` / `ORDER_DEFAULT` |
| サポート詐欺・フィッシング | 電話ではなく画面に入力させる手口なので、戦国シールドの対象外 | — |

変わらない決まり: AIは振り込む・渡す・行く・待つの約束をしない。架空の口座番号や家の住所も言わない。110番はAIが自分でかけない。
