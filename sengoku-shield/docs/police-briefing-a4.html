鮮刻シールド(せんこくシールド)のご説明

詐欺の電話に「出てしまった後」の高齢者を支える、スマホの見守りアプリ(試作・無料)

作ったきっかけ

藤枝市で魚屋を営む48歳です。十数年前、私の母が詐欺の電話で約100万円をだまし取られました。「電話に出てしまった後に、本人がひとりで判断しなくてすむ仕組み」があれば防げたのではないかと思い、生成AIを使って個人で開発しています。

どう動くか(今、実際に動いている機能)

  1. 電話をスピーカーにして、そばにスマホを置きます。スマホが相手の言葉を文字にして、詐欺によくある言い回し(還付金・ATM・口止め・口座の不正利用など)に気づきます。
  2. 怪しいときは、やさしい音で知らせ、「大丈夫です。お金のことは今は答えなくて大丈夫です」という文と、時間をかせぐ一言(「メガネを落としちゃって、ちょっと待ってね」など)、「AIに代わる」ボタンを出します。
  3. 本人がボタンを押すと、AIが本人に代わって応対し、相手の名前・所属・金額・口座・会う日時と場所を聞き返して記録します。
  4. 電話のあと、110番や #9110 でそのまま読める文を画面に出します(いつ・誰を名乗り・何を言われたか)。
  5. 登録した家族のLINEに、相手が言ったことと読み上げ用の文を知らせます(LINEは接続の最終設定中)。動揺している本人に代わり、家族が相談できるようにするためです。

守っている決まり(安全のため、あえて入れていないこと)

  • 電話を切る・AIに代わるのは、必ず本人の操作です(自動では切り替えません)。
  • AIが自分で110番したり、警察に自動で送信・中継したりはしません(「警察に中継中」など事実でない表示もしません)。
  • AIは、振り込む・渡す・行く・待つといった約束をしません。架空の口座番号や住所も言わず、家に来るよう誘いません。
  • 会う日時・場所が出たら、すぐ110番するよう案内します。「だまされたふり作戦」は警察の指示に従う考えです。
  • 本人や家族の声をまねる機能(声のクローン)は入れていません。悪用の道具になるためです。

確かめていること

  • 普通の電話(病院・お店・家族など)93件で、誤って詐欺と判定した数は0件。
  • 静岡県警・警視庁・千葉県警などが公開している実際の詐欺電話の録音で検証しています。
  • 正直に申し上げると、まだ見逃しもあります。改善を続けています。

今の状況と予定

  • 試作の段階です。スマホのブラウザだけで動きます(工事不要)。
  • 12月中旬に、家族・知人の数軒で試してもらう予定です(無料)。
  • 販売や宣伝の前に、警察の方のご意見をいただきたいと考えています。

ご相談・お願いしたいこと

  1. この地域で今多い手口や言い回し(特に「電話が止まる」など通信会社を名乗る型)を教えていただけないでしょうか。
  2. 画面の言葉や110番の案内の仕方で、直したほうがよい点があればご指摘ください。
  3. AIが聞き出した情報(名前・口座・日時場所など)は、どんな形でお伝えすると捜査や相談の役に立ちますか。
  4. このような仕組みで、気をつけるべき点(運用・法律の面など)があれば教えてください。
