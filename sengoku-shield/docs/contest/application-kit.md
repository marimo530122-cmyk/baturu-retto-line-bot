## 2. 強み(審査員に伝える3つ)

### ① 信頼性を「数字」で確かめ続けている
- 普通の電話(宅配・病院・家族など)93件で、**誤って警告を出したのは0件**。ルールを変えるたびに自動で確かめている。
- 警察が公開している**本物の詐欺電話の録音 107件**で、改良の効果を測る仕組みがある。
- 自動テスト 133件。記録はハッシュでつないだ監査ログに残し、書き換えを検出できる。
- 正直な数字も出している: ルール作りに使った例文では 90.8%(69/76)を検知、**ルール作りに使わない「答え合わせ用」の例文では 43.4%(23/53)**。
  「見たことのない言い回しはまだ半分以上を逃す」ことを隠さず、本物の録音で測りながら改善している。

### ② 「やらないこと」を決めた安全設計
- 電話を勝手に切らない。AIに代わるのも必ず本人の操作。
- AIは「振り込む・渡す・会う」などの約束をしない。架空の口座番号も言わない(本物と一致すると迷惑がかかるため)。
- 本人や家族の声のまね(声のクローン)は作らない(それ自体が詐欺の道具になるため)。
- 犯人が「これまでの指示を無視しろ」などとAIを操ろうとしたら、その回はAIを使わない。AIの返事も毎回機械で確かめる。
- 画面の言葉は、お年寄りを怖がらせないやさしい文面にしている。「警察に中継している」など事実でない安心材料は書かない。

### ③ 地元の警察・家族と一緒に作っている
- 地元の手口(藤枝・焼津・島田・牧之原の4署合同の防犯動画など)を資料にしている。
- 2026年10月28日、警察署を訪ね、A4の説明書と見守り画面を見せた。
  【要確認: 警察の方の言葉「非常に有難いです」を応募に引用してよいか。署名を出してよいか】
- 家族に犯人役をしてもらう、本物の電話での試験の台本を用意している(試験はこれから)。

## 6. note 記事の骨組み

**タイトル案**
1. 母が詐欺で100万円を取られた魚屋が、AIと「詐欺の電話のあと」を守る道具を作った話
2. 48歳の魚屋、AIと二人三脚で詐欺電話対策ツールを作る
3. 「電話を取ったあと」に被害を止める。地元の警察署に見せに行った試作品の話

**見出しと要点**
1. **きっかけ**: 母の被害(約100万円)。「電話の前」の対策はあるのに「取ってしまったあと」が空白だと気づいた。
2. **どんなものか**: 見守り画面 → やさしい声かけ → AIに代わる → 家族のLINE。デモのURL(https://sengoku-shield.onrender.com/demo)を貼る。
3. **あえてやらないこと**: 勝手に切らない、声のまねは作らない、AIは約束しない。理由も書く(ここが読者の心に残る)。
4. **正直な数字**: 誤検知 0/93、答え合わせ用は 43%。「まだ半分以上を逃す。だから本物の録音で測って直している」。
5. **地元の警察署へ**: 10月28日に見せに行った話【要確認: 書いてよい範囲】。
6. **これから**: 本物の電話での試験、12月15日のモニター配布。モニターになってくれる家族を募集(投げ銭のお願いはここ)。
