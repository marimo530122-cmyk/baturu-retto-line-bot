スマホだけで置く手順

パソコンもTwilioも使わずに、鮮刻シールドをインターネット上(Render というサービス)に置く手順です。スマホのブラウザだけでできます。

Twilioは後回しで大丈夫です

Twilioが無くても、見守り画面(スピーカーにした電話の声を聞いて詐欺を判定し、言い訳とボタンを出す)・家族のLINE登録と知らせ・ClaudeとJevの判定は動きます。止まるのは「AIが電話に出る」と「家族への自動電話」の2つだけです。Twilioの設定を後から足せば、その2つも自動で動き始めます。

用意するもの

  • GitHubのアカウント(もう持っています)
  • Renderのアカウント(render.com。GitHubでログインできます)
  • クレジットカード(Renderの有料プランのため)
  • あれば: Claude(Anthropic)のAPIキー、LINEの鍵、TypeSafeのキー。無くても置けます。後から足せます。

お金について

家族の名簿を消さずに保存するため、ディスク付きの「Starter」プランにしてあります。目安は月7ドル前後(約1,000円)+ディスク代わずかです。正確な金額は申し込む前にRenderの画面で確認してください。無料プランでも動きますが、再起動のたびに家族の登録が消えます。

置く手順(10〜15分)

  1. スマホのブラウザで dashboard.render.com を開き、「GitHubでログイン」を選ぶ。
  2. 「New」→「Blueprint」を選ぶ。
  3. GitHubの連携を許可し、リポジトリ baturu-retto-line-bot を選ぶ。
  4. ブランチを選ぶ欄があれば main を選ぶ。
  5. Renderが設定ファイル(render.yaml)を読み、sengoku-shield というサービスが表示される。
  6. 鍵の入力欄(ANTHROPIC_API_KEY など)が出る。持っている鍵だけ、ここに直接貼る。無いものは空のままでよい。
  7. 「Apply」(作成)を押す。数分で起動します。

鍵はチャットに貼らないでください

鍵を入れる場所は、Renderの画面の入力欄だけです。Claude Codeにも貼る必要はありません。万一どこかに貼ってしまったら、発行元のサイトで作り直してください。

置いた後にやること

  1. Renderの sengoku-shield の画面の上にある URL(https://sengoku-shield-xxxx.onrender.com のような形)を確認する。
  2. そのURLの後ろに /health を付けて開き、ok と出れば動いています。
  3. 「Environment」を開き、SHIELD_APP_TOKEN の値(Renderが自動で作った合言葉)を表示してコピーする。
  4. URLの後ろに /app を付けて開くと見守り画面。画面下の「合言葉」欄に貼る(一度入れればスマホが覚えます)。
  5. LINEを使う場合: LINE Developers の Webhook URL を、URLの後ろに /line/webhook を付けたものにする。

後から鍵を足すとき

Renderの sengoku-shield →「Environment」→「Add Environment Variable」で、名前と値を入れて保存します。自動で再起動して使えるようになります。

足したいこと入れる名前
AIの返事を自然にするANTHROPIC_API_KEY
Jevの判定TYPESAFE_API_KEY
家族へのLINELINE_CHANNEL_SECRET・LINE_CHANNEL_ACCESS_TOKEN・SHIELD_LINE_ADD_URL
AIが電話に出る(Twilio)TWILIO_AUTH_TOKEN
家族への自動電話(Twilio)TWILIO_ACCOUNT_SID・SHIELD_CALLER_ID
AIの声を男性にSHIELD_VOICE_GENDER を male

公開URL(SHIELD_PUBLIC_URL)は、Renderでは自動で入るので設定不要です。
