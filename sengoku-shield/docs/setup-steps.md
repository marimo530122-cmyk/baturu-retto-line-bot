# かんたん設定手順(Web・LINE共通の元データ)

チラシ裏面(`flyer-draft.md`)の設定手順を、今の戦国シールドで本当にできる形に直して整理したもの。
中身は `setup-steps.json` にあり、Webページ(`web`)とLINEの返信(`line`、1通500字以内)の両方で使い回せる。
チラシにはあるがまだ作っていないものは `status: "planned"` と、足りないもの(`missing`)を書いてある。

## 手順(今の戦国シールドでできること)

**前もって**: 実家の固定電話で NTT の「ボイスワープ」(転送サービス)の契約が必要(月額数百円。申し込みは116。料金はNTTで確認)。

| # | やること | 誰が | 目安 |
|---|---|---|---|
| 1 | LINEで友だち追加し、見守り画面の6桁の招待番号を送って家族登録(自動電話も受けるなら携帯番号も送る) | 家族のスマホ | 2分 |
| 2 | 実家の電話で142 → 転送先に戦国シールドの番号 → 「無応答時転送」・呼び出し15〜20秒(5回ほど)。留守番電話は20秒より長く | 実家の固定電話 | 5分 |
| 3 | 家族の携帯から実家にかけ、20秒出ずに待ってAIが出るか確かめる | 家族の携帯 | 3分 |
| 4 | あとは普段どおり。出られなかった電話にAIが出て、疑いが高いときだけ家族のLINEに知らせと110番の台本が届く | 操作なし | — |

## チラシを配る前に直すところ

| チラシの記載 | 問題 | 直し方の案 |
|---|---|---|
| 「鮮刻シールド」 | 他の資料・公式LINE ID(`@sengoku_shield`)は「戦国」。音声入力の変換違いかも | どちらかにそろえる |
| 「家族のLINEへ即時**中継**」「LINEへ**通報**」 | 通話を中継しているわけでも、警察に通報しているわけでもない(事実でない安心材料は書かない決まり) | 「家族のLINEへすぐお知らせ」「110番で読める台本もお届け」 |
| FAQ「AIは詐欺特有の言い回しのみを検知して作動」 | 実際は、出られなかった電話にはすべてAIが出る。家族に知らせるのが疑いの高いときだけ | `setup-steps.json` の FAQ の書き方にする |
| 「追加料金0円」「3分で完了」 | ボイスワープの契約(NTTの月額料金)が別に必要。書いていないと後でトラブルになる | 「別途NTTのボイスワープ契約(月額)が必要」を明記 |
| 「呼び出し回数を5回」 | ボイスワープは回数ではなく秒数で決める | 「呼び出し時間15〜20秒(5回ほど)」 |
| 「新規お申し込み」「実家専用の050番号」 | まだ作っていない(今は戦国シールドの番号が1つだけ。家ごとに番号を取るにはTwilioの番号を家の数だけ契約する) | 作るまでは手順から外す |
| 月額980円 | 料金の受け取りの仕組みがまだ無い。家ごとの原価(050番号の月額・通話料・AIの利用料)もまだ計算していない | 原価を出してから決める |
| 24時間AIサポート窓口、`support@sengoku-shield.jp`、`@sengoku_shield` | まだ無い(ドメイン・メール・LINE IDを取ったか未確認) | 用意できてから載せる |

有料で広く配る前に、確かめておいた方がよいこと:
- 無いサービスを載せたチラシは、景品表示法の「優良誤認」になるおそれがある。
- 有料サービスには、特定商取引法の表示・利用規約・プライバシーポリシー(相手の通話を文字にして残すため)が要る。
- 他人の電話を受けて転送するサービスとして、電気通信事業の届出が要るかどうか(総務省の窓口で確認)。

まずは家族・知人の数軒に無料で使ってもらい、実際の電話で確かめてから有料にする順番がおすすめ。
