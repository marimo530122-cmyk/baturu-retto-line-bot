# 規約チェッカー

利用規約や同意文を貼るだけで、自動更新・解約の条件・違約金など、契約前に気をつけたい文に色を付ける無料の道具です。
貼った文章はどこにも送らず、あなたのブラウザの中だけで調べます。

## 使い方

1. ページを開き、規約や同意文の文章を欄に貼る。
2. 「調べる」を押す。
3. 注意したい文に色と種類の札が付く。色が付かない文も、必ず自分で読む。

見つける7種類: 自動更新/解約の条件/第三者提供/無料期間後の課金/返金不可/違約金・解約金/最低利用期間

## 大事な決まり

- 画面の「見落としがありえます。最終確認はご自身で」は外さない。
- 外との通信は CSP で止めている。外部のスクリプト・フォント・解析タグを足さない。
- 言葉のリストは独自に作ったもの。考え方は修士研究 baltpeter/thesis-mobile-consent-dialogs(MIT)を参考にしたが、コード・データは取り込んでいない。

## 公開

`.github/workflows/terms-checker-pages.yml` が、main に入ったときに `index.html` だけを GitHub Pages に公開する。
初回だけ、リポジトリの Settings → Pages → Source を「GitHub Actions」にする。
