# 衛星監視室(orbit-watch)

スマホのブラウザでも動く、作戦室風の衛星追跡画面。`index.html` を開くだけで動く(ビルド不要)。
ショート動画のネタ用の「撮影モード」と、宇宙ステーション(ISS)が肉眼で見える日時の予報がある。

## 公開とデータ

- 公開: `.github/workflows/orbit-watch-pages.yml` が GitHub Pages に載せる
  (main への push・毎日 03:07 JST・手動実行)。初回だけ Settings → Pages の Source を「GitHub Actions」にする。
- データ: 公開のたびに `tools/fetch-tle.mjs` が CelesTrak から肉眼で見える明るい衛星(`GROUP=visual`、約150個)と、
  ISS・しきさい(GCOM-C)・しずく(GCOM-W)・ひまわり8/9号を取り、`data/tle.json` として一緒に載せる。
  `data/` は Git に入れない。取れない日は公開中の前回分を使い、それも無ければ公開を更新しない(前のページが残る)。
  CelesTrak は同じデータを2時間に1回より多く取らないよう求めているので、手元で何度も回さないこと。
- ページは `data/tle.json` → CelesTrak に直接 → 練習用の合成データ の順に試す。右上に「本物のデータ ◯/◯取得」か「練習用データ」と出る。

## 中身

- 計算: [satellite.js](https://github.com/shashwatak/satellite-js) v5.0.0(MIT)の SGP4。`vendor/` に同梱。
- 判定(JEV風): 各衛星に決まった質問(頭上を通るか/他の物体と近いか/落ちかけか/高楕円か/太陽同期か)をして
  `choice` と `score` で答え、平常・注意・警戒を決める。理由も表示する。1問が壊れても全体は止まらない。
  「危険度」「警戒」は演出で、本当の危険を表すものではない(使い方にもそう書いてある)。
- ISSの予報: 衛星が地平線から10°以上・空が暗い(太陽が地平線の6°下より下)・衛星に日が当たっている、の3つがそろう時間を
  72時間先まで20秒きざみで探し、境目は1秒きざみで詰める。別の天文ライブラリ(astronomy-engine)で太陽を計算した
  検算と、テストデータ5件で開始時刻が分単位まで一致することを確認済み。
- 現在地: 「📍現在地」を押したときだけ取る。端末の中の計算にだけ使い、送らない・保存しない。画面には小数1桁(約10km)まで。
- 描画: Canvas 2D の正射影。陸地は Natural Earth 1:50m を2°格子にした点を `app.js` に埋め込み。高さは対数で縮めて表示。
- 画面の言葉はすべて日本語。初回は「使い方」が開く(右上の「？使い方」でいつでも開ける)。

## 撮影モード(🎬撮影)

約30秒、縦長(9:16)の演出が自動で流れる。3・2・1のあいだにスマホの画面収録を始める。最初の20秒は共通
(接続 → 観測地点を特定 → 上空の衛星を最大4個ロックオン → 上空の数で警告)、最後の10秒が編ごとに違う。

| 編 | 本題 |
|---|---|
| ① 頭上編 | 次にISSが見える日時と方角 |
| ② 魚屋編 | しきさい(海面水温・海の色)/しずく(雲の下の海面水温)と、漁場の予想に使われていること |
| ③ 宇宙ゴミ編 | 上空(または追跡中)の物体のうちロケットの残骸・破片の数 |

締めは「あなたの頭上も調べられます → プロフのリンクから」。撮影中は座標を ██ で黒塗りにし、地図上の印も
±0.4°以内でずらし、ログから地点の行を外す(録画に居場所を映さないため。外さないこと)。
練習用データのときは「※練習用データ」と画面上部に出る。数字はすべて計算結果、説明文は公表されている事実の範囲で書く。

画面の「機密」「傍受」などは演出。画面下部の「実在の機密情報ではありません」の注記は消さないこと。
