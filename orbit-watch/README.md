# ARGUS//NULL — 軌道監視シミュレーター(MVP)

スマホのブラウザでも動く、作戦室風の衛星追跡画面。`index.html` を開くだけで動く(ビルド不要)。

- 計算: [satellite.js](https://github.com/shashwatak/satellite-js) v5.0.0(MIT)の SGP4。`vendor/` に同梱しているので CDN 不要。
- 軌道データ: 起動時に CelesTrak の公開TLE(`GROUP=visual`)を取りに行く。5秒で取れなければ、
  実在の軌道の「型」(ISS級・太陽同期・GPS級・モルニヤ・静止・コンステレーション・デブリ)を真似た合成要素に切り替える。
  合成のときは画面右上が `SYNTH · OFFLINE`、本物のときは `LIVE · CELESTRAK` になる。
- 判定(JEV風): 各衛星に決まった質問(頭上を通るか/他の物体と近いか/落ちかけか/高楕円か/太陽同期か)をして
  `choice` と `score` で答え、合計で NOMINAL / WATCH / ALERT を決める。理由も表示する。
  1問が壊れても全体は止まらない。外から来たTLEはチェックサムで検査してから使う。
- 描画: Canvas 2D の正射影。陸地は Natural Earth 1:50m を2°格子にした点(約2KB)を `app.js` に埋め込み。
  高度は対数で縮めて表示(外側リング = 静止軌道)。
- 操作: ドラッグで回転、ピンチ/ホイールで拡大、タップで衛星を選択。
  `ROT` 自動回転 / `×1` 時間加速(×1→×10→×60→×600)/ `SITE◎` 画面中央を観測地点に / `SND` 警報音。

画面の「機密」「傍受」などは演出。位置は公開データからの推定値で、本物の機密情報ではない
(画面下部にもそう書いてある。消さないこと)。
