# ブラウザ情報もれ診断

今使っているブラウザから、ウェブサイトにどんな情報が見えている可能性があるかを、その場で調べて一覧にする無料の道具です。
読み取った情報は保存も送信もせず、画面に表示するだけです。

## 調べる10項目

ユーザーエージェント/画面の大きさ・色の数/タイムゾーン/言語/Canvas の目印(ハッシュ)/WebGL の部品名/
Cookie が使えるか/localStorage が使えるか/Do Not Track の設定/ネットのつながり方(navigator.connection があるときだけ)

各項目に「何が見えている?」「なぜ気をつける?」を一言ずつ付け、最後に「◯項目中◯項目が見えています」を出す。

## 大事な決まり

- 読み取った情報は保存も送信もしない。localStorage・Cookie にも書き込まない(使えるかどうかを見るだけ)。
- 外との通信は CSP で止めている。例外はページ下の広告(A8.net の NordVPN バナー)の画像2つだけ(規約チェッカーと同じ)。
- 広告には「広告」「【PR】」を付け、断定・誇大な文言は書かない。説明も「見える可能性がある」と断定しない形にする。
- 発想は EFF の Privacy Badger(GPL-3.0)を参考にしたが、コードは一切使っていない(新しく書いたもの)。
