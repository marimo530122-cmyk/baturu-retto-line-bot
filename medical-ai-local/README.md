# 医療AI ローカル完結アプリ（プロトタイプ）

マイク音声のリアルタイム文字起こしから、主訴・治療方針・処方・紹介状ドラフトの自動生成までを、
**外部のクラウドAPI（OpenAI等）に一切データを送信せず**、このPC内だけで完結させるプロトタイプです。

- バックエンド: `main.py`（FastAPI, 単一ファイル）
- フロントエンド: `index.html`（ビルド不要のVanilla JS 単一ファイル）
- 音声認識: [faster-whisper](https://github.com/SYSTRAN/faster-whisper)（このPC上で実行）
- カルテ生成: [Ollama](https://ollama.com)（このPC上で動くローカルLLMサーバーにHTTP接続）

## 「本当に外部に送信されないの？」について（正直な説明）

**実行中（マイクで話している間・カルテを生成している間）は、音声・会話内容・生成結果は
一切インターネットに送信されません。** スマホから使う場合も、通信は同じWi-Fi内（PCとスマホの
間）だけで閉じており、外部のインターネットには出ていきません。すべてこのPC上のプロセス間
（ブラウザ ⇔ FastAPI ⇔ `localhost:11434` の Ollama）だけで完結します。

ただし、以下の**準備作業だけ**は初回にインターネット接続が必要です（これらはソフトウェアや
モデルの「重み」をダウンロードするだけで、患者データとは無関係です）。

- `pip install` によるPythonパッケージのダウンロード（初回のみ）
- Whisperモデルの重みのダウンロード（初めてマイクで発話した時に自動実行、以後は不要）
- Ollamaのインストール、および使用するLLMモデルの重みのダウンロード（`ollama pull` 時のみ）

これらが完了した後は、Wi-Fi/LANを切断した状態でも動作します。

## セットアップ手順

### 0. コード一式をパソコンにダウンロードする（まだの場合）

1. ブラウザで以下のURLを開く（**アドレスバーに入力してEnter**。検索窓ではなくアドレスバーです）

   ```
   https://github.com/marimo530122-cmyk/baturu-retto-line-bot/archive/refs/heads/claude/medical-ai-prompt-setup-2o9ief.zip
   ```

2. ZIPファイルがダウンロードされるので、ダウンロードフォルダなどに展開（解凍）する
3. 展開してできたフォルダの中にある `medical-ai-local` フォルダが、これから使うフォルダです

### 1. Ollama（ローカルLLM）をインストールする

1. https://ollama.com からご自身のOS用のインストーラーをダウンロードしてインストールする
2. ターミナル（Windowsの場合はコマンドプロンプト/PowerShell）で、使用するモデルを取得する

   ```bash
   ollama pull llama3.2
   ```

   （PCのスペックに応じて選んでください。軽くて速い順に `llama3.2:1b` → `llama3.2` →
   `llama3.1:8b` などがあります。日本語の医療文書としての精度を重視するなら `llama3.1:8b`
   以上のサイズを推奨しますが、CPUのみだと生成に時間がかかります。）

3. Ollamaは通常インストール後にバックグラウンドで自動起動し、`http://localhost:11434`
   で待ち受けます。起動していない場合は `ollama serve` を実行してください。

### 2. アプリを起動する

**Windowsの場合**: `medical-ai-local` フォルダを開き、`start.bat` を**ダブルクリック**してください。
黒い画面（コマンドプロンプト）が開いて自動でセットアップ・起動が進みます。
（Pythonが入っていない場合は先に https://www.python.org/downloads/ からインストールしてください。
インストール時に「**Add python.exe to PATH**」に必ずチェックを入れてください。これを忘れると
`start.bat` が「pythonが見つかりません」というエラーになります。）

途中で「Windows セキュリティの重要な警告」が表示されたら、「プライベートネットワーク」に
チェックが入っていることを確認して「アクセスを許可する」を選んでください（同じWi-Fi内の
スマホからアクセスするために必要な許可です）。

**Mac/Linuxの場合**: ターミナルを開いて以下を実行してください。

```bash
cd medical-ai-local
./start.sh
```

初回はPythonパッケージのインストールに少し時間がかかります。起動すると、ターミナルに
以下のような案内とQRコードが表示されます。

```
 [PCから] https://localhost:8443
 [同じWi-FiのスマホやPCから] https://192.168.x.x:8443

 ↓ スマホのカメラでこのQRコードを読み取るとアクセスできます
 █▀▀▀▀▀█ ▄▄██ █▀▀▀▀▀█
 ...(QRコード)...
```

### 3. PCのブラウザで開く

`https://localhost:8443` を開いてください。自己署名証明書のため警告が出ますが、
下記「スマホから接続する」の手順3と同じ要領で進めば開けます。

### 4. スマホから接続する（同じWi-Fiに接続していること）

1. スマホを、**PCと同じWi-Fi（同一LAN）**に接続する（モバイル回線ではアクセスできません）
2. スマホのカメラでターミナルに表示されたQRコードを読み取るか、表示された
   `https://192.168.x.x:8443` のURLをスマホのブラウザに直接入力する
3. 「この接続ではプライバシーが保護されません」「保護されていない通信」等の警告が出るので、
   これは想定内です（自己署名証明書のため）。以下の要領で進んでください。
   - **Android（Chrome）**: 「詳細設定」→「(IPアドレス)にアクセスする（安全ではありません）」
   - **iPhone（Safari）**: 「詳細を表示」→「このWebサイトを閲覧」
4. 画面中央の大きなマイクのボタンが表示されたら、マイクへのアクセスを許可する

（iPhoneは iOS 14.3 以降のSafariで動作確認できる想定です。古いiOSやアプリ内ブラウザでは
マイク録音がうまく動作しない場合があります。）

### 5. 使ってみる

操作はとてもシンプルです。

1. 画面中央の大きな🎤ボタンを**1回タップ**する（赤く光って「聞いています…」になります）
2. そのまま話しかける（数秒ごとに自動で文字起こしされます）
3. 話した内容から、「主訴・症状」「治療方針」「処方内容」「紹介状」のカードが**自動で**
   増えていきます（手動でどの項目か選ぶ操作は一切不要です）
4. 話し終えたら、もう一度🎤ボタンをタップして録音を止める
5. マイクが使えない環境では、「マイクが使えない場合」を開いてキーボードで直接入力しても
   同様に動作します
6. 次の患者さんの診察を始めるときは、一番下の「🆕 次の患者さん（内容をリセット）」を押してください

画面右上の「詳細情報」からは、使用中のAIモデル名や接続状況（Ollamaに繋がっているか等）の
技術的な情報を確認できます（普段の操作では見なくて大丈夫です）。

## 動作環境・モデルについてのメモ

- **Whisperモデルのサイズ**: デフォルトは `small`（日本語の精度と速度のバランス重視）です。
  環境変数 `WHISPER_MODEL_SIZE`（`tiny`/`base`/`small`/`medium`/`large-v3` など）で変更できます。
  CPUのみの環境で重い場合は `base` や `tiny` に下げると速くなります（精度は下がります）。
- **GPU利用**: NVIDIA GPU環境では `WHISPER_DEVICE=cuda WHISPER_COMPUTE_TYPE=float16 ./start.sh`
  のように指定すると高速化できます（CUDA対応のPyTorch/CTranslate2環境が別途必要です）。
- **Ollamaのモデル変更**: 環境変数 `OLLAMA_MODEL` で使用するモデル名を切り替えられます。
- **音声チャンクの区切りについて**: マイク入力は約6秒ごとに区切って文字起こしする方式です。
  区切りの前後で単語が途切れて認識精度が落ちる場合があります（`index.html` 内の `CHUNK_MS`
  で調整可能）。より高精度を求める場合は、発話の区切り（間）で区切る実装への拡張を検討してください。
- **話者分離（誰が話したか）は自動判定していません**: 1本のマイクからの入力のため、
  画面上のプルダウンで医師/患者を手動切り替えする方式です。自動話者分離（diarization）は
  本プロトタイプの範囲外です。
- **医師の文体再現**: クラウド版（`medical-ai/`）にある医師プロファイル・過去実例を使った
  文体模倣機能は、本ローカル版には含まれていません（必要であれば同様の仕組みを追加できます）。

## セキュリティに関する注意

- **同じWi-Fi内の他の端末からアクセスできる状態になります**（`0.0.0.0` にバインドしているため）。
  カフェの公衆Wi-Fiなど、他人も接続できるネットワークでは実行しないでください。自宅・院内の
  信頼できるWi-Fiでのみ使用することを想定しています。
- 生成される自己署名証明書（`certs/` フォルダ）はこのPC専用の秘密鍵を含みます。他人と共有したり
  Gitにコミットしたりしないでください（`.gitignore` で除外済みです）。

## トラブルシューティング

- **スマホでURLを開いても繋がらない/読み込み中のまま**: (1) スマホとPCが本当に同じWi-Fi
  ルーターに接続されているか（ゲストWi-Fiやモバイル回線になっていないか）、(2) PC側の
  ファイアウォールがポート8443への接続をブロックしていないか（Windowsのファイアウォール
  設定で許可が必要な場合があります）、を確認してください。
- **証明書の警告から先に進めない**: ブラウザによって表示文言が異なります。「詳細」「Advanced」
  「このまま続ける」に類するリンク・ボタンを探してください。それでも進めない場合、ブラウザの
  セキュリティ設定が厳しめの可能性があります（別のブラウザを試す、上記READMEの手順を再確認）。
- **「ローカルLLM: 未接続」のまま変わらない**: `ollama serve` が起動しているか、
  `ollama pull llama3.2` でモデルを取得済みか確認してください。
- **マイクの文字起こし結果が空になる**: ブラウザのマイク権限、マイクデバイスの選択、
  無音でないかを確認してください。Chrome/Edge/Firefoxでの利用を推奨します（Safariは
  `MediaRecorder` の対応形式が異なるため動作しない場合があります）。
- **初回のマイク発話時にサーバーが固まったように見える**: Whisperモデルの初回ダウンロード・
  読み込み中です。モデルサイズによっては数十秒かかることがあります。ターミナルのログを
  確認してください。
